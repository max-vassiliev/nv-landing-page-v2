# Наталья Васильева — основной сайт, версия 2

Одностраничный сайт. Статика: HTML + CSS + немного ванильного JS, без сборки
и зависимостей. Открывается двойным кликом по `index.html`.

## Структура

```
index.html     разметка всех десяти экранов
styles.css     токены палитры, компоненты, адаптив
script.js      липкая шапка, мобильное меню, появление при скролле, счётчики
favicon.svg    иконка вкладки
img/nv-main.jpg  портрет для первого экрана
```

## Экраны

1. Первый экран — заголовок, лид, подпись, портрет
2. Обо мне + факты-акценты
3. Направления — две карточки

Дальше идут два направления. Каждое — отдельная глава `.direction`:
своим заголовком `<h2>` и общим фоном на оба экрана, чтобы при скролле
было видно, в каком направлении читатель. Заголовки экранов внутри
главы — `<h3>`, заголовки карточек — `<h4>`.

4-5. **Business & Commercial Growth** (белый фон): «Когда бизнесу нужен
     следующий этап роста», «Опыт, который превращается в результат»
6-7. **Доверяя своей природе** (тёмно-зелёный фон): «Когда прежний способ
     жить и действовать больше не работает», «Интегративный подход»

8. Биография и дипломы — **плейсхолдер**, ссылка на текущий сайт
9. Идеи и публикации
10. Приглашение — контакты

Копирайт: `../nv-landing-page-v02-files/copy/nv_landing-page_v02_copy.md`

## Палитра и шрифты

Источник — `NV/design/nv-brand-colors-fonts.md`: тиффани `#0abab5`,
тёмно-зелёный `#1d3a38`, заголовки Montserrat, текст Aptos → Helvetica Neue.

Для текста и для фонов под белым текстом используется затемнённый тиффани
`#0a7570`: брендовый `#08938e` даёт всего 3.6:1 на светлом фоне и не проходит
WCAG AA на мелком тексте. Яркий `#0abab5` остаётся только для декора.
